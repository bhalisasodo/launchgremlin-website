# LaunchGremlin — 30/60/90-Day Content Execution Calendar

**Five pillars, one engine:** Cold-Call Reels · Vibe-Coding Events · Music Video Competition · Educational/Content Hub · Need Money for Maserati

Core rule from the strategy report: organic proves it, paid amplifies it, cadence beats polish. Every pillar feeds the same tracking sheet (views/saves/comments/shares) — winners get paid spend regardless of which pillar they came from.

---

## DAYS 1–30 — Build the Engine (No Paid Spend)

**Goal:** Establish posting cadence, build the avatar feed, get the first event and competition announced, start logging data.

| Pillar | Weekly Actions | Output |
|---|---|---|
| Cold-Call Reels | Film 3–5 real prospect calls/reactions from LeadGremlin pipeline | 3–5 reels/week across IG, FB, TikTok |
| Vibe-Coding Events | Pick venue + date for Event #1 (Umhlanga or Ballito); start online promo | Event page live, 2–3 teaser posts |
| Music Video Competition | Finalize NO SKIP track for the brief; draft rules + prize; open call for videographers | Competition brief published, 1–2 announcement posts |
| Educational/Content Hub | Repurpose 2 Content Hub pieces/week into reels (business-card generator, pricing myths) | 2 posts/week |
| Need Money for Maserati | Post daily — building-in-public narrative tying all above together | 5–7 posts/week (can be light: stories, captions, progress notes) |

**Also this phase:**
- Set up the avatar faux-feed (per report) to sanity-check tone/format choices.
- Build a single tracking sheet: pillar, post, date, views, saves, comments, shares.
- No Meta spend yet — this month is pure signal-gathering.

---

## DAYS 31–60 — Validate, Launch the Big Swings, Start Paid

**Goal:** Run Event #1, open the video competition for entries, identify top-performing organic posts and start small paid tests behind them.

| Pillar | Actions |
|---|---|
| Cold-Call Reels | Keep cadence (3–5/week); double down on formats that got saves/shares in Month 1 |
| Vibe-Coding Events | **Run Event #1** — batch-record all footage same day (talking clips, before/after, client-voice testimonials, build-in-public shots) |
| Music Video Competition | Entries open; post submission highlights/BTS from competing videographers as they trickle in (free amplification — they'll share their own entries) |
| Educational/Content Hub | Continue 2/week; start weaving in questions/pain points surfaced from cold calls and the event |
| Need Money for Maserati | Weave in Event #1 highlights and competition buzz as "proof of momentum" content |
| **Paid (new this phase)** | Identify 2–3 best organic posts across all pillars; put ~R150–200/day behind each; rotate in 1–2 new creatives every few days |

**Also this phase:**
- Re-batch Event #1 footage across 3–4 formats each (per report: one story → carousel, talking clip, before/after, caption-only post) to resupply the other pillars for the next few weeks.
- Track which pillar is producing the best organic pull — that tells you where to lean Month 3.

---

## DAYS 61–90 — Systemise and Scale Volume

**Goal:** Lock in a repeatable weekly system, run Event #2, judge/announce the music video winner, scale ad spend only behind proven creative.

| Pillar | Actions |
|---|---|
| Cold-Call Reels | Fully systemised — same day/week for batch calls, same day for editing/posting |
| Vibe-Coding Events | **Run Event #2** at a second venue; compare turnout/content yield vs. Event #1 to decide monthly vs. bi-monthly cadence going forward |
| Music Video Competition | Close entries → judge → **announce winner**; winning video becomes the official music video — this is a major shareable moment across all channels |
| Educational/Content Hub | Retire formats that underperformed; double down on what worked (myth-busting seems likely given the report's emphasis) |
| Need Money for Maserati | Use the competition winner announcement + Event #2 as the "biggest proof of momentum yet" narrative beat |
| Paid | Scale budget only behind creative with proven organic pull; keep testing 1–2 new pieces every few days so performance doesn't decay |

**Also this phase:**
- Revisit the avatar feed — check if the audience's taste has shifted after 2 months of data.
- Decide event cadence for Q2 (monthly seems supportable if Event #1/#2 both produce enough batch content).
- Set the next competition (new artist/track) if the music video pillar proves itself.

---

## Cross-Pillar Guardrails

- Every post passes one filter: does this help, entertain, or reassure the SA small-business viewer — or is it just talking about LaunchGremlin?
- One tracking sheet, all five pillars — paid spend follows data, not pillar preference.
- Batch-record on event days; don't try to post "in the moment."
- The Maserati account is the connective narrative — it should reference real proof points (calls landed, events run, competition entries) rather than running as a separate content stream.
